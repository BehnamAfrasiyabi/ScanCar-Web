# SCAN CAR Brand Standard

This repository follows the ScanCar product branding standard.

## Canonical identity

- Company: SCAN CAR
- Product: S1
- Product brand: SCANCAR S1
- Canonical logo: `ScanCar-Web/images/logo.png`

## Usage rules

- Customer-facing product name must be displayed as `SCANCAR S1`.
- The company name is `SCAN CAR`.
- The product model is `S1`.
- Use the canonical ScanCar logo consistently across web, app, firmware UI and documentation where a logo is required.
- Do not introduce alternative product names such as `SCARDIAG` in customer-facing branding.
- Technical identifiers such as package names, storage keys, repository names and API identifiers may remain unchanged when changing them would be unnecessary or breaking.

## Fixed technical exception

The ESP32 Access Point SSID `SCARDIAG-XXXX` is a finalized technical protocol value and must not be renamed as part of visual branding changes.

## Brand hierarchy

SCAN CAR = company
S1 = product model
SCANCAR S1 = customer-facing product name
